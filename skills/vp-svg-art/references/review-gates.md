# Shared artwork review gates

These gates are integrated into both production skills. They do not rely on a third skill activating. Each distributed skill contains a local copy so it can work without a sibling installation.

## Contract before candidates

Record output family, mode, reference/brief authority, identity/story/color/composition requirements, permitted adaptations, native/minimum sizes, backgrounds, exact edit tasks and required consuming contexts. Scale detail to the task. A small color edit does not require a new art-direction exercise.

With a source image, inspect actual pixels before constructing candidates and freeze localized required/simplifiable/optional roles. A generated prompt is not image evidence. With a text brief only, derive criteria from explicit requirements and declared creative choices; do not manufacture a reference image or source ROI. A generated or self-selected anchor remains provisional unless the user/project gave it authority.

## Non-compensating gates

| Gate | Establishes | Does not establish |
| --- | --- | --- |
| source suitability, when a reference exists | The reference can support the actual intended output, with recorded adaptations/conflicts | User brand approval, finished native pixels/vectors, or downstream acceptance |
| technical | Declared format/grid/palette/alpha/viewBox/vector structure, source rebuild and requested edit mechanics | Recognizability, style quality, narrative fidelity or target-app behavior |
| visual | Each required/simplifiable role reads at actual size/polarity; whole-image identity, composition, hierarchy and craft satisfy the declared brief | Every future device, human approval or another app |
| target use, when required | Actual requested browser/layout/editor/engine/export/device behavior for exact assets | A different consumer/action or broad compatibility |

A failed required gate cannot be offset by a beautiful image, smaller file or higher average score. Optional craft is separate. A component being present is not proof of its readable object/function/action. For critical tiny negative openings and separated accents, inspect native-size polarity; geometry or antialias haze alone cannot establish a readable gap. Repair a dedicated optical variant while preserving larger accepted masters.

A reference gate is conditional: create-from-brief with no reference skips source-image suitability, not technical/visual/use review. A review-only request does not mutate art. Treat an explicitly approved unusual style as a constraint, not a defect to replace by generic taste.

## Evidence and independence

Bind asset, brief, reference/inventory and actual inspected output by content hash where the workflow relies on reusable acceptance receipts. Record feature, view, region, observation and consequence; whole-image observations are for whole-composition claims. An edited asset/brief/preview invalidates the affected receipt. A requested screenshot size or filename is insufficient: compare actual captured dimensions and live viewport. Mismatched evidence leaves that context unverified rather than proving an art defect.

Independent review needs actual authorized separate execution. Give the reviewer the ordinary brief, source, required constraints and real outputs without producer ratings or an intended winner. A file claiming independence does not establish it. Missing vision or independence cannot be patched with a generic compliment.

## Outcomes and loop

- blocked: a required technical/input condition prevents producing the declared deliverable. An absent production path is distinct from a deliverable whose required verification is unavailable.
- revise: current evidence shows a required visual/use criterion fails.
- needs_review: required visual/context/authority/independence evidence is missing or stale, including unavailable target verification for an otherwise constructible candidate. Neither this nor blocked permits a ready claim.
- ready: all required gates pass for the exact declared revision, use, review mode and authority. State that scope; this is not universal professional/brand approval.

Correct specific authorized failures and rerun affected comparisons. Preserve accepted versions and failed experiments. A new required regression is rejected/reverted or repaired before adoption; do not lower frozen criteria, use majority vote, or average the failure away. Stop at satisfied declared gates or a specific unavailable dependency. When another iteration adds no evidence, report that limit rather than expanding optional polish indefinitely.
