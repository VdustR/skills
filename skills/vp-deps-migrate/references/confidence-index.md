# Confidence

Report confidence only when it helps choose migration scope or review depth.
Base it on:

- completeness of usage classification;
- quality of primary guidance;
- runtime and data compatibility;
- test coverage of changed behavior;
- size and reversibility of the migration;
- unresolved generated, consumer, or environment dependencies.

Use plain high, medium, or low confidence with the decisive evidence and
remaining uncertainty. A numeric score suggests precision the evidence rarely
supports.
