# Package Managers

Use the repository's declared package manager, lockfile, workspace layout, and
current help. Do not mix managers or hand-edit generated lock data.

Distinguish direct dependencies, peer requirements, workspace constraints,
optional packages, and tooling-only packages. A package removal is incomplete
until the manifest, lockfile, imports, configuration, generated artifacts, and
related scripts agree.

Do not install a different package manager or bypass frozen-lockfile policy
without authorization.
