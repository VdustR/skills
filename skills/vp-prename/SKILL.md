# Prename

Name the durable objective or outcome, not the latest command. Prefer a short
title with concrete nouns and an action or state when useful. Avoid dates,
generic labels, tool names, ticket identifiers without context, and claims of
completion when work is unfinished.

Return only the title unless the user asks for alternatives or rationale.
