# Package Managers

Use the repository-declared package manager, workspace scope, lockfile policy,
and current help. Avoid unrelated lockfile churn.

Confirm whether the requested dependency is direct, transitive, peer, optional,
or generated by another tool. Use the manager's supported override or resolution
mechanism only when the repository already accepts it or the tradeoff is
explicitly approved.

Do not mix package managers, hand-edit generated lock data, or bypass frozen
lockfile checks to force an upgrade through.
