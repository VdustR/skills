# Dependency Bot Pull Requests

Record the evaluation time and head commit, then independently inspect the full
diff, manifests, lockfile, generated files, release guidance, and checks.

Bot summaries, compatibility scores, and prior green runs may be incomplete or
stale. Confirm the update scope, related packages, source migrations, security
claims, and current required checks.

Keep bot-authored PRs in draft or blocked when material compatibility risk,
unhandled feedback, or missing verification remains. Follow the normal PR
lifecycle and authorization rules for replies, readiness, and merge.
